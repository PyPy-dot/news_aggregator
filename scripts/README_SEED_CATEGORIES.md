# 📊 Категории новостей по умолчанию

Этот скрипт создаёт категории новостей по умолчанию в базе данных.

## Запуск

```bash
cd /Users/vladvolk/Documents/проекты/news_aggregator
.venv/bin/python scripts/seed_categories.py
```

## Категории по умолчанию

- Политика
- Экономика
- Общество
- Происшествия
- Спорт
- Технологии
- Наука
- Культура
- Здоровье
- Образование
- Погода
- Воздушная тревога
- Экстренные новости

## Проверка

После запуска скрипта проверьте, что категории созданы:

1. Запустите бота
2. Перейдите в **Админ-меню** → **Каналы публикации** → **➕ Добавить канал**
3. Нажмите **"➕ Выбрать канал для публикации"** и выберите канал
4. Должно появиться меню выбора категории

Если категории не появились — проверьте логи бота, там должно быть:
```
📊 Загружено категорий из БД: 13
✅ Категории для выбора: ['Воздушная тревога', 'Здоровье', ...]
```
