# 🔐 Авторизация Telegram (Listener Bot)

## ⚠️ Важно: Безопасность авторизации

**Telegram блокирует передачу кодов авторизации третьим лицам**, включая ботов. Это мера безопасности для защиты вашего аккаунта.

**Никогда не передавайте код авторизации:**
- Ботам (включая этого бота)
- Другим людям
- Через сообщения

## ✅ Правильный способ авторизации

### Консольная авторизация (рекомендуется)

1. **Запустите бота:**
   ```bash
   python3 main.py
   ```

2. **Дождитесь запроса кода:**
   ```
   🔐 АВТОРИЗАЦИЯ TELEGRAM
   ============================================================
   
   📱 Код будет отправлен в ваше приложение Telegram
      (на этом или другом устройстве)
   
   ⚠️ ВАЖНО:
      • Не пересылайте код никому!
      • Telegram блокирует передачу кодов третьим лицам
      • Введите код прямо в этой консоли
   
   📤 Запрос кода у Telegram...
   
   🔢 Введите 5-значный код из Telegram:
      Код: _
   ```

3. **Получите код в Telegram:**
   - Откройте Telegram (приложение или веб-версию)
   - Найдите сообщение от Telegram с 5-значным кодом
   - Сообщение приходит в личные сообщения от системного аккаунта Telegram

4. **Введите код в консоль:**
   ```
      Код: 12345
   ✅ Код принят!
   
   ============================================================
   ✅ АВТОРИЗАЦИЯ УСПЕШНА
   ============================================================
   ```

5. **Готово!** Listener Bot авторизован и готов к работе.

## 🔑 Облачный пароль Telegram

Если у вас включён **облачный пароль Telegram** (двухфакторная защита аккаунта):

1. После ввода кода появится запрос:
   ```
   🔒 Требуется облачный пароль Telegram
      Облачный пароль: _
   ```

2. Введите ваш облачный пароль Telegram

3. ✅ Авторизация завершена!

> **Примечание:** Не путайте **облачный пароль Telegram** с **2FA для команд бота**.
> - Облачный пароль защищает ваш аккаунт Telegram (настраивается в Telegram)
> - 2FA защищает команды бота (настраивается через `/2fa setup`)

## 📱 Где найти код

Код от Telegram приходит в:
- **Мобильное приложение Telegram** (iOS/Android)
- **Telegram Desktop** (Windows/macOS/Linux)
- **Веб-версия** (https://web.telegram.org/)

**Ищите сообщение от системного аккаунта Telegram** (не от бота!).

## ⏱️ Время действия кода

- Код действителен **~2 минуты**
- Введите код быстро после получения
- Если код истёк — перезапустите бота для нового запроса

## 🚫 Частые ошибки

### "Код не приходит"
- Убедитесь, что вы авторизованы в Telegram на каком-либо устройстве
- Проверьте спам в Telegram
- Подождите 1-2 минуты — код может прийти с задержкой

### "PhoneCodeInvalidError"
- Вы ввели неверный код
- Код истёк (прошло больше 2 минут)
- **Решение:** Перезапустите бота и запросите новый код

### "FloodWaitError"
- Слишком много запросов кода
- Telegram временно ограничил запросы
- **Решение:** Подождите указанное время (от 10 минут до нескольких часов)

## 💾 Сессия

После успешной авторизации создаётся файл сессии:
- **Файл:** `userbot.session`
- **Расположение:** корневая директория проекта
- **Срок действия:** бессрочно (пока не удалите)

**Не удаляйте файл сессии** — иначе потребуется повторная авторизация.

## 🔒 Безопасность

- Храните файл `userbot.session` в секрете
- Не передавайте файл сессии другим
- При компрометации — удалите сессию в настройках Telegram

## 🆘 Проблемы с авторизацией?

1. **Проверьте логи** — там есть подробная информация об ошибке
2. **Перезапустите бота** — это запросит новый код
3. **Проверьте Telegram** — код должен прийти в приложение
4. **Подождите** — если получили FloodWait, нужно подождать указанное время
