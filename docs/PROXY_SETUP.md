# 🔑 Настройка прокси для ListenerBot

## Проблема

Если при запуске приложения вы видите ошибку:
```
TimeoutError: Connection timed out
```
или
```
ListenerBot не запущен. Приложение продолжает работу без мониторинга каналов.
```

Это означает, что Telegram заблокирован на уровне провайдера в вашем регионе.

## Решение

### Вариант 1: Использование VPN (рекомендуется)

1. Подключите VPN (любой сервис: NordVPN, ExpressVPN, ProtonVPN и т.д.)
2. Запустите приложение:
   ```bash
   python3 main.py
   ```

### Вариант 2: Настройка прокси в приложении

#### 1. Найдите прокси-сервер

Вы можете использовать:
- **Публичные прокси** (не рекомендуются для production):
  - https://www.proxy-list.download/
  - https://www.spys.one/en/socks-proxy-list/
  
- **Платные прокси-сервисы** (рекомендуется):
  - Bright Data
  - Smartproxy
  - IPRoyal

- **Собственный прокси-сервер** (лучший вариант):
  ```bash
  # Настройка SOCKS5 прокси на собственном сервере
  ssh -D 1080 -N user@your-server.com
  ```

#### 2. Добавьте прокси в .env

Откройте `.env` и добавьте:

**Для SOCKS5 прокси:**
```bash
TELEGRAM_PROXY=socks5://hostname:port
# Пример:
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

**Для HTTP прокси:**
```bash
TELEGRAM_PROXY=http://hostname:port
# Пример:
TELEGRAM_PROXY=http://127.0.0.1:8080
```

**С авторизацией:**
```bash
# Telethon не поддерживает авторизацию напрямую
# Используйте локальный прокси-сервер с авторизацией
```

#### 3. Запустите приложение

```bash
python3 main.py
```

### Вариант 3: Временное решение (мобильный хот-спот)

1. Подключитесь к мобильному интернету (другой провайдер)
2. Запустите приложение для авторизации
3. После успешной авторизации сессия сохранится в файле `userbot.session`
4. Теперь приложение будет работать и через основной интернет

## Проверка подключения

Для проверки доступности Telegram запустите:

```bash
python3 -c "
import asyncio
import socket

async def test():
    dcs = [
        ('149.154.167.50', 443, 'DC1'),
        ('149.154.166.110', 443, 'DC2'),
        ('149.154.175.51', 443, 'DC3'),
        ('149.154.167.91', 443, 'DC4'),
        ('149.154.171.5', 443, 'DC5'),
    ]
    
    for ip, port, dc in dcs:
        try:
            reader, writer = await asyncio.wait_for(
                asyncio.open_connection(ip, port),
                timeout=5.0
            )
            print(f'✅ {dc} ({ip}:{port}) - доступен')
            writer.close()
            await writer.wait_closed()
        except Exception as e:
            print(f'❌ {dc} ({ip}:{port}) - {type(e).__name__}')

asyncio.run(test())
"
```

Если все DC недоступны — нужен прокси или VPN.

```
✅ Подключение установлено
```

## Troubleshooting

### Ошибка: `ModuleNotFoundError: No module named 'socks'`

Установите библиотеку pysocks:
```bash
pip install pysocks
```

### Ошибка: `Connection refused`

Прокси-сервер недоступен. Проверьте:
- Правильность hostname и port
- Работает ли прокси-сервер
- Не блокируется ли сам прокси

### Ошибка: `FloodWaitError`

Слишком много попыток авторизации. Подождите указанное время (от 1 часа до нескольких дней).

## Безопасность

⚠️ **Не используйте публичные бесплатные прокси для production!**

Публичные прокси могут:
- Перехватывать ваши данные
- Логировать ваши сообщения
- Быть заблокированными Telegram

Используйте только доверенные прокси-сервисы или собственные серверы.
