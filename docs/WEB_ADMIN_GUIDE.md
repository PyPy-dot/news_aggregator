# Web Admin Panel — Руководство по использованию

**Версия:** 1.0.0  
**Дата:** 2026-08-13

## Обзор

Web Admin Panel — современный веб-интерфейс для администрирования News Aggregator.

### Возможности

- 📊 **Главная панель** — статистика системы, статус сервисов, последние новости
- 📰 **Новости** — управление новостями, модерация, публикация
- 📡 **Каналы** — управление Telegram-каналами (источники и публикации)
- 👥 **Пользователи** — управление пользователями и подписками
- 📋 **Задачи** — планировщик задач, мониторинг выполнения
- 📰 **RSS ленты** — управление RSS-источниками
- 🌐 **Web парсинг** — управление веб-парсерами
- 💻 **Консоль** — SQL, Python, БД инструменты
- ⚙️ **Настройки** — конфигурация системы

## Быстрый старт

### Запуск с основным приложением

Web Admin автоматически запускается вместе с основным приложением:

```bash
python main.py
```

После запуска:
- Админ-панель откроется автоматически в браузере: http://localhost:8001
- Или откройте вручную: http://localhost:8001

### Отдельный запуск (разработка)

```bash
cd /Users/vladvolk/Yandex.Disk.localized/news_aggregator
source .venv/bin/activate

python -m services.web_admin.api.app
```

Или через uvicorn напрямую:

```bash
uvicorn services.web_admin.api.app:app --reload --host 0.0.0.0 --port 8001
```

## Аутентификация

### Вход в систему

1. Откройте http://localhost:8001
2. Нажмите "Войти" в правом верхнем углу
3. Введите ваш Telegram ID (можно узнать в @userinfobot)
4. Если включена 2FA, введите код из аутентификатора
5. Нажмите "Войти"

### JWT токены

- Токены хранятся в HTTP-only cookies
- Время жизни: 24 часа
- Автоматическое продление сессии

### 2FA (TOTP)

Для администраторов с включенной 2FA:
- Используйте коды из Google Authenticator / Authy
- Или используйте резервные коды

## Интеграция с основным приложением

Web Admin интегрирован в `main.py` как отдельный сервис:

```python
from services.web_admin.service import WebAdminService

class Application:
    def __init__(self):
        self.web_admin_service = WebAdminService(host="0.0.0.0", port=8001)
    
    async def run(self):
        # Запуск Web Admin
        self._web_admin_task = asyncio.create_task(
            self._run_web_admin(), name="web_admin"
        )
```

### Конфигурация

Параметры Web Admin в `WebAdminService`:

```python
WebAdminService(
    host="0.0.0.0",      # Хост для прослушивания
    port=8001,           # Порт
    reload=False,        # Перезагрузка при изменениях (dev mode)
    log_level="info",    # Уровень логирования
)
```

## Безопасность

### Рекомендации для production

1. **Смените JWT_SECRET** в `services/web_admin/api/auth.py`:
   ```python
   JWT_SECRET = "your-super-secret-key-change-in-production"
   ```

2. **Включите HTTPS**:
   - Используйте reverse proxy (nginx)
   - Настройте SSL сертификаты

3. **Установите COOKIE_SECURE = True**:
   ```python
   COOKIE_SECURE = True  # Только HTTPS cookies
   ```

4. **Ограничьте доступ**:
   - Используйте firewall
   - Настройте IP whitelist
   - Включите rate limiting

## Troubleshooting

### Web Admin не запускается

1. Проверьте, свободен ли порт 8001:
   ```bash
   lsof -i :8001
   ```

2. Проверьте логи приложения:
   ```bash
   tail -f logs/app.log
   ```

3. Убедитесь, что зависимости установлены:
   ```bash
   pip install -r requirements.txt
   ```

### Не открывается браузер автоматически

- Откройте вручную: http://localhost:8001
- Проверьте, что браузер по умолчанию настроен в системе

### Ошибка аутентификации

1. Убедитесь, что пользователь существует в БД
2. Проверьте, что у пользователя роль 'admin'
3. Если включена 2FA, используйте правильный TOTP код
