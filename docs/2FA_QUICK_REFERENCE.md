# 📋 2FA — Краткая справка

## Переключение между провайдерами

### Текущая конфигурация

Проверить текущий провайдер:
```bash
grep LISTENER_2FA_PROVIDER .env
```

### Смена провайдера

**Шаг 1:** Откройте `.env` и измените:
```bash
# Для Google Authenticator
LISTENER_2FA_PROVIDER=google

# Для Яндекс.Ключ
LISTENER_2FA_PROVIDER=yandex
```

**Шаг 2:** Перезапустите бота:
```bash
# Ctrl+C для остановки
python3 main.py  # для запуска
```

**Шаг 3:** В боте проверьте статус:
```bash
/2fa status
```

## Сравнение провайдеров

| Характеристика | Google Authenticator | Яндекс.Ключ |
|---------------|---------------------|-------------|
| **Доступность** | Глобально | РФ |
| **VPN** | Может требоваться | Не требуется |
| **Приложения** | Все TOTP-совместимые | Все TOTP-совместимые |
| **Формат URI** | Стандартный otpauth:// | Стандартный otpauth:// |
| **Резервные коды** | Нет (только в нашем боте) | Нет (только в нашем боте) |

## Рекомендации

- **Если есть VPN** → Google Authenticator (более распространён)
- **Если нет VPN** → Яндекс.Ключ (работает без ограничений)
- **Для команды** →统一 выбрать один провайдер для всех

## Команды управления

```bash
/2fa              # Меню
/2fa setup        # Настроить
/2fa disable      # Отключить
/2fa status       # Статус
/2fa provider     # Сменить провайдер
```
