# 📊 2FA — Итоговая сводка изменений

## ✅ Реализовано

### 1. Поддержка двух провайдеров TOTP

**Файл:** `services/auth/two_factor_auth.py`

- Добавлен параметр `provider` ('google' или 'yandex')
- Метод `get_provisioning_uri()` поддерживает оба формата URI
- Метод `get_setup_instructions()` возвращает инструкцию для текущего провайдера
- Singleton `get_2fa_service()` читает провайдер из настроек

### 2. Настройки в конфигурации

**Файл:** `config/settings.py`

```python
listener_2fa_enabled: bool      # Включить 2FA
listener_2fa_secret: str | None # Секретный ключ
listener_2fa_provider: str      # 'google' или 'yandex'
```

**Файл:** `.env.example`

```bash
LISTENER_2FA_ENABLED=true
LISTENER_2FA_PROVIDER=google  # или yandex
LISTENER_2FA_SECRET=  # генерируется автоматически
```

### 3. Обновлённые хендлеры бота

**Файл:** `services/bot/handlers/two_factor_auth.py`

- `/2fa setup` — использует инструкции текущего провайдера
- `/2fa status` — показывает текущий провайдер
- `/2fa provider` — новая команда для смены провайдера (интерактивная клавиатура)
- Callback хендлеры для кнопок выбора провайдера

### 4. Документация

**Файлы:**
- `docs/2FA_SETUP.md` — полная инструкция по настройке
- `docs/2FA_QUICK_REFERENCE.md` — краткая справка

## 🔧 Как использовать

### Быстрая настройка

1. В `.env` укажите:
   ```bash
   LISTENER_2FA_ENABLED=true
   LISTENER_2FA_PROVIDER=google  # или yandex
   ```

2. Перезапустите бота

3. В боте выполните:
   ```bash
   /2fa setup
   ```

4. Отсканируйте QR-код в приложении аутентификатора

5. Сохраните резервные коды

### Смена провайдера

1. В боте выполните:
   ```bash
   /2fa provider
   ```
   Выберите провайдер из кнопок

2. Если 2FA включена — сначала отключите:
   ```bash
   /2fa disable
   ```

3. Измените в `.env`:
   ```bash
   LISTENER_2FA_PROVIDER=yandex  # или google
   ```

4. Перезапустите бота

5. Настройте заново:
   ```bash
   /2fa setup
   ```

## 🔒 Уровни защиты

Система использует **два уровня 2FA**:

### 1. Telegram 2FA (облачный пароль)
- Защищает аккаунт Telegram
- Запрашивается при авторизации в новом устройстве
- Настраивается в настройках Telegram

### 2. Наш 2FA (TOTP)
- Защищает доступ к функциям бота
- Требуется для административных команд
- Настраивается через `/2fa setup`

Оба уровня работают **независимо** и дополняют друг друга.

## 🎯 Рекомендации

1. **Включите оба уровня 2FA** для максимальной защиты
2. **Сохраните резервные коды** в надёжном месте
3. **Выберите один провайдер** для всей команды
4. **Регулярно проверяйте статус**: `/2fa status`
