# Консоль управления — Руководство пользователя

## Обзор

Консоль управления — это инструмент администрирования News Aggregator, предоставляющий доступ к:
- **Терминалу** для выполнения команд управления
- **Python** для выполнения произвольного кода
- **SQL** для выполнения запросов к базе данных
- **Управлению сервисами** (старт/стоп/рестарт)

## Доступ

Консоль доступна по адресу: `http://localhost:8001/console` (после авторизации)

## Вкладки

### 1. Терминал

Основной интерфейс для взаимодействия с системой.

#### Команды управления

| Команда | Описание |
|---------|----------|
| `help` | Показать список всех команд |
| `status` | Показать статус всех сервисов |
| `start <service>` | Запустить сервис (bot, listener, scheduler) |
| `stop <service>` | Остановить сервис |
| `restart <service>` | Перезапустить сервис |
| `start-all` | Запустить все сервисы |
| `stop-all` | Остановить все сервисы |
| `clear` | Очистить терминал |
| `version` | Показать версию приложения |
| `list channels` | Показать последние 10 каналов |
| `list users` | Показать последних 10 пользователей |
| `stats` | Показать статистику системы |

#### Примеры

```
$ help
$ status
$ start bot
$ stop-all
$ restart scheduler
$ stats
```

#### Индикаторы статуса

В шапке страницы отображаются индикаторы статуса трёх сервисов (обновляются каждые 5 сек):

| Индикатор | Сервис |
|-----------|--------|
| 🟢 Зелёный + пульсация | Бот работает |
| 🟡 Жёлтый | Запуск/остановка |
| 🔴 Красный | Остановлен / упал |

При наведении — uptime (например, `● 2ч 15м`) или информация об ошибке.

**Кнопка «Старт»** — disabled когда все сервисы запущены.
**Кнопка «Стоп»** — disabled когда все сервисы остановлены.

#### Кнопки управления

**Глобальное управление:**
- **Старт** — запуск всех сервисов (scheduler → bot → listener)
- **Стоп** — остановка всех сервисов (listener → bot → scheduler)

**Индивидуальное управление:**
- **Бот** — рестарт Admin Bot
- **Лисенер** — рестарт Listener Bot
- **Шедулер** — рестарт Scheduler
- **Очистить** — очистка терминала

#### Логирование в терминал

Все действия (запуск/остановка сервисов, ошибки, команды) выводятся непосредственно в терминал с цветовой индикацией:
- 🟢 Зелёный — успешные операции
- 🔴 Красный — ошибки и остановки
- 🟡 Жёлтый — предупреждения и информация

### 2. Python

Выполнение Python кода напрямую в контексте приложения.

#### Возможности

- Доступ к встроенным функциям Python
- Вывод результатов через `print()`
- Обработка ошибок выполнения

#### Примеры кода

```python
# Простой вывод
print("Hello, World!")

# Работа с данными
numbers = [1, 2, 3, 4, 5]
print(f"Sum: {sum(numbers)}")

# Дата и время
from datetime import datetime
print(f"Current time: {datetime.now()}")
```

### 3. SQL

Выполнение SQL запросов к базе данных.

#### Поддерживаемые операции

- `SELECT` — получение данных
- `INSERT` — добавление записей
- `UPDATE` — обновление записей
- `DELETE` — удаление записей

#### Запрещённые операции

- `DROP` — удаление таблиц
- `TRUNCATE` — очистка таблиц
- `ALTER` — изменение структуры
- `CREATE` — создание объектов
- `GRANT` / `REVOKE` — управление правами

#### Примеры запросов

```sql
-- Получить последнего пользователя
SELECT * FROM users ORDER BY id DESC LIMIT 10;

-- Посчитать количество новостей
SELECT COUNT(*) FROM telegram_posts;

-- Получить активные каналы
SELECT id, name, telegram_id FROM channels WHERE active = true;
```

## API эндпоинты

Консоль предоставляет следующие API для программного доступа:

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/console/api/execute` | Выполнить команду |
| POST | `/console/api/python` | Выполнить Python код |
| POST | `/console/api/sql` | Выполнить SQL запрос |
| GET | `/console/api/status` | Получить статус сервисов |
| POST | `/console/api/{service}/start` | Запустить сервис |
| POST | `/console/api/{service}/stop` | Остановить сервис |
| POST | `/console/api/{service}/restart` | Перезапустить сервис |

### Примеры запросов

#### Выполнить команду

```bash
curl -X POST http://localhost:8001/console/api/execute \
  -H "Content-Type: application/json" \
  -H "Cookie: web_admin_session=<token>" \
  -d '{"command": "status"}'
```

#### Запустить сервис

```bash
curl -X POST http://localhost:8001/console/api/bot/start \
  -H "Cookie: web_admin_session=<token>"
```

#### Выполнить SQL запрос

```bash
curl -X POST http://localhost:8001/console/api/sql \
  -H "Content-Type: application/json" \
  -H "Cookie: web_admin_session=<token>" \
  -d '{"query": "SELECT * FROM users LIMIT 5"}'
```

## Безопасность

### Требования авторизации

Все эндпоинты консоли требуют авторизации через cookie `web_admin_session`.

### Ограничения

1. **Python код** выполняется в том же процессе — избегайте опасных операций
2. **SQL запросы** фильтруются на предмет опасных операций (DROP, TRUNCATE, etc.)
3. **Остановка сервисов** требует подтверждения через UI

## Поддерживаемые ANSI цвета

Терминал поддерживает ANSI цвета для форматирования вывода:

| Код | Цвет | Использование |
|-----|------|---------------|
| `\x1b[32m` | Зелёный | Успешные операции |
| `\x1b[31m` | Красный | Ошибки, остановки |
| `\x1b[33m` | Жёлтый | Предупреждения, информация |
| `\x1b[36m` | Голубой | Заголовки, информация |
| `\x1b[1m` | Жирный | Выделение |
| `\x1b[0m` | Сброс | Возврат к стилю по умолчанию |

### Примеры использования

```
\x1b[32m✅ Успешно\x1b[0m
\x1b[31m❌ Ошибка\x1b[0m
\x1b[33m⚠️ Предупреждение\x1b[0m
\x1b[1;36mЗаголовок\x1b[0m
```

## Интеграция с основным приложением

Консоль интегрирована в основное приложение через:

1. **Маршруты**: `services/web_admin/routes/console.py`
2. **Шаблон**: `services/web_admin/templates/console.html`
3. **API**: FastAPI endpoints с префиксом `/console`

## Расширение функциональности

Для добавления новых команд:

1. Откройте `services/web_admin/routes/console.py`
2. Добавьте обработку команды в функцию `execute_command`
3. Обновите документацию

Пример добавления команды:

```python
elif cmd == "mycommand":
    output = "\x1b[32mРезультат выполнения\x1b[0m"
    # Ваша логика здесь
```
