# 🔐 Настройка двухфакторной аутентификации (2FA)

## Обзор

Система поддерживает два провайдера 2FA:
- **Google Authenticator** — стандартный TOTP, поддерживается всеми приложениями
- **Яндекс.Ключ** — российское приложение, работает без VPN

Оба провайдера используют один и тот же алгоритм TOTP (RFC 6238), поэтому совместимы с любыми TOTP-приложениями:
- Google Authenticator
- Яндекс.Ключ
- Authy
- Microsoft Authenticator
- 2FAS
- Raivo OTP
- И другие

## 📋 Быстрый старт

### 1. Включить 2FA в настройках

В файле `.env` установите:

```bash
# Включить 2FA
LISTENER_2FA_ENABLED=true

# Выбрать провайдер (google или yandex)
LISTENER_2FA_PROVIDER=google
```

### 2. Настроить 2FA в боте

1. Отправьте боту команду `/2fa setup`
2. Отсканируйте QR-код в приложении аутентификатора
3. Введите 6-значный код из приложения
4. Сохраните резервные коды в надёжном месте

### 3. Проверить статус

```bash
/2fa status
```

## 🔄 Смена провайдера

Если вы хотите сменить провайдера (например, с Google на Яндекс):

**Важно:** Если 2FA уже включена, сначала отключите её!

1. Отключите текущую 2FA:
   ```bash
   /2fa disable
   ```

2. Измените провайдер в `.env`:
   ```bash
   LISTENER_2FA_PROVIDER=yandex  # или google
   ```

3. Перезапустите бота:
   ```bash
   # Остановите бота (Ctrl+C)
   python3 main.py  # запустите заново
   ```

4. Настройте 2FA заново:
   ```bash
   /2fa setup
   ```

## 🛠️ Команды управления 2FA

| Команда | Описание |
|---------|----------|
| `/2fa` | Главное меню 2FA |
| `/2fa setup` | Настроить 2FA |
| `/2fa disable` | Отключить 2FA |
| `/2fa status` | Проверить статус |
| `/2fa provider` | Сменить провайдер |

## 🔑 Резервные коды

При настройке 2FA вы получите 10 резервных кодов. Используйте их, если:
- Потеряли доступ к приложению аутентификатора
- Сломался телефон
- Нужно срочно войти в систему

**Важно:**
- Каждый код можно использовать только один раз
- Храните коды в надёжном месте (менеджер паролей, распечатка)
- Если использовали все коды — настройте 2FA заново

## 🔒 Как это работает

1. При настройке генерируется секретный ключ (32 символа, base32)
2. Ключ сохраняется в базе данных и в вашем аутентификаторе
3. Аутентификатор генерирует 6-значные коды каждые 30 секунд
4. При входе система проверяет код с допуском ±1 интервал (90 секунд)

## ⚠️ Troubleshooting

### Код не принимается

1. **Проверьте время на устройстве** — оно должно быть синхронизировано
2. **Подождите новый код** — коды обновляются каждые 30 секунд
3. **Попробуйте резервный код** — если есть

### Потерял доступ к приложению

Используйте резервные коды, которые вы получили при настройке:
```bash
# Введите резервный код вместо TOTP
```

Если резервных кодов нет — обратитесь к другому администратору для сброса 2FA через базу данных.

### Хочу сменить приложение аутентификатора

1. Отключите 2FA: `/2fa disable`
2. Настройте заново: `/2fa setup`
3. Отсканируйте QR-код в новом приложении

## 📊 Статус 2FA

Проверить статус можно командой:
```bash
/2fa status
```

Вы увидите:
- ✅ 2FA включена / ❌ не включена
- 🔹 Провайдер (Google или Яндекс)
- ✅ Резервные коды есть / ❌ нет
